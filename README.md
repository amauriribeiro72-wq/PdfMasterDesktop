# PDF Master Pro - Windows Desktop Edition 🚀

Aplicativo Desktop de alta performance para Windows 10 e 11, projetado para manipulação completa de documentos PDF, 100% offline e com privacidade total.

---

## ✨ Principais Funcionalidades

- **📑 Mesclagem Avançada**: Junte múltiplos documentos PDF em uma única saída de forma rápida.
- **🗜️ Otimização & Compressão**: Reduza o tamanho dos arquivos PDF removendo redundâncias sem perda de legibilidade.
- **🛡️ Marca d'Água**: Insira carimbos personalizados e confidenciais em páginas com ângulo e opacidade ajustáveis.
- **🔒 Segurança & Criptografia**: Bloqueie PDFs com senha de usuário e proprietário.
- **✍️ Assinatura Digital ICP-Brasil**: Suporte a certificados digitais Windows (A1 e A3/Token).
- **🔍 OCR Nativo do Windows**: Reconhecimento óptico de caracteres embutido.

---

## 💻 Como Instalar

1. Acesse a aba **Actions** neste repositório.
2. Abra a última execução de compilação (**Compilar PDF Master Desktop**).
3. Na seção **Artifacts**, baixe o pacote **PdfMaster-Windows-Instalador**.
4. Descompacte o arquivo `.zip` e execute `PdfMaster_Windows_Setup.exe`.
5. Pronto! O atalho será criado na sua Área de Trabalho e no Menu Iniciar.
